# AR Prototype 7

What went well?
Getting the ocean to move and the code for moving was easy, but everything else went a lot less well

What didn’t go well?
In Unity, the piano mode works well, but on itch the piano doesn't work at all, the keys are stretched, and the notes fall in the wrong areas

What challenges did you face? (Technical, creative, or production)
Most of the challenge came from the piano mode. Initially, I thought I could do something like in my previous prototype where the camera would switch to a different location, and then the piano and notes would fall down in 3d but then I thought maybe it could be easier in a panel, but I had a rough time getting that to work. Finally, when I put it on itch, the game didnt work at all

What can you do differently next time?
Stick with the easiest option that I know can work
